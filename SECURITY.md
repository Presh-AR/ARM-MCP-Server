# Security Policy

## Supported Versions

Security fixes are applied to the latest release line.

| Version | Supported |
| --- | --- |
| 0.5.x | Yes |
| Earlier versions | No |

## Report a Vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/AutoRABIT-AI/ARM-MCP-Server/security/advisories/new) and include:

- Affected version and environment
- Reproduction steps or a proof of concept
- Expected and observed impact
- Any suggested remediation

Never include live AutoRABIT tokens, customer data, or tenant URLs in a report. Replace secrets with test values and revoke any credential that was exposed.

We will acknowledge the report, assess severity, and coordinate remediation and disclosure through the private advisory.
