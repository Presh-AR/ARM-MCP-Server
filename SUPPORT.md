# Support

Use the channel that matches the request:

- MCP server defect or feature request: [GitHub Issues](https://github.com/AutoRABIT-AI/ARM-MCP-Server/issues)
- Suspected vulnerability: [private security advisory](https://github.com/AutoRABIT-AI/ARM-MCP-Server/security/advisories/new)
- AutoRABIT product, tenant, licensing, or API-token support: [AutoRABIT Support](https://support.autorabit.com/)
- ARM product documentation: [AutoRABIT Knowledge Base](https://knowledgebase.autorabit.com/)

Include the MCP server version, Node.js version, client name, sanitized configuration, and reproducible steps. Remove tokens, customer data, and tenant-specific identifiers before sharing logs.
